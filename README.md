# 「滑著手機的我們，還在真正溝通嗎？」簡報

這是一份用網頁做的簡報，不需要網路、不需要安裝任何東西。全部 93 個畫面（beat）：按一下，就換下一個。

## 怎麼打開

1. 用 **Chrome** 或 **Edge**，雙擊資料夾裡的 `index.html`。
2. 第一次開會等幾秒鐘（載入字型和 3D），出現封面就可以開始了。
3. 想直接跳到某一頁，在網址最後面加 `#數字`，例如 `index.html#41` 會跳到第 41 個畫面（封面是 0）。

## 按鍵

| 按鍵 | 功能 |
|---|---|
| → ／ 空白鍵 ／ 滑鼠左鍵 | 下一步 |
| ← ／ 滑鼠右鍵 | 上一步 |
| N | 顯示／隱藏講稿 |
| P | 開「講者視窗」（看講稿、下一頁預覽；可以放在另一個螢幕） |
| F | 全螢幕 |
| T | 白天／夜晚主題切換（教室很亮時可以改白天） |
| `#數字` | 網址後面加 `#n`，直接跳到第 n 個畫面 |

## 報告人的名字寫在哪裡

打開 `js/content.js`（用記事本就可以），找到這一行：

```
const PRESENTER = '';
```

把兩個引號中間填上名字，例如 `const PRESENTER = '王小明';`，存檔後在瀏覽器按 F5 重新整理，名字就會出現在封面左下角的日期旁邊。同一個檔案裡的 `COURSE` 是課程名稱，也可以改。

## 講稿和「按一下」怎麼對應

- 講稿放在 `js/notes.js`。
- 每一段文字就是「按一下」要講的話，順序和畫面一對一。例如第 1 個畫面（火鍋桌）對應「open」這一組的第 1 句。
- 按 N 或 P，就會看到目前這一下該講的那一段。
- `js/notes.js` 和 `docs/script.txt` 是自動產生的，**請不要直接改**。要改講稿，請改原始講稿再重新產生。

## 注意

- 畫面裡的 3D 火鍋桌和咖啡廳需要 **WebGL**。請**事先在要報告的那台電腦上完整按過一遍**，確認 3D 畫面正常、字型有出現。
- 簡報用到的字型（粉圓體）和 3D 程式都已經放在資料夾裡，所以沒有網路也能報告。請把整個資料夾一起複製，不要只複製 `index.html`。
- 畫面不會自己動。每一個動畫都是你按下去之後才開始，約 2 秒內停下來。
- 如果 3D 畫面很卡，把瀏覽器的「硬體加速」打開，或換成另一個瀏覽器（Chrome／Edge）試試。
